# ANALYSIS.md — Agent B

## 1. Назначение и стек
Веб-дашборд акций (Django + DRF + Celery + T-Invest API).  
Agent B модернизировал проект и добавил **виртуальный инвестиционный портфель**.

Стек после модернизации: Django 4.2+, DRF, Bootstrap 5, SQLite/Postgres, опционально t-tech-investments.

## 2–6. Архитектура (кратко)
- `Share` — инструмент
- `Portfolio` / `PortfolioItem` / `PortfolioTransaction` — виртуальный портфель пользователя
- CBV + LoginRequiredMixin
- Сервис `dashboard.services.portfolio` — атомарные buy/sell со средней ценой
- REST API акций без изменения контракта

## Восстановленные ФТ

1–12. Базовые требования исходного приложения (список, деталь, CRUD для auth-пользователей, регистрация, Celery update price, API, admin, add_shares).

### Новые ФТ (реализовано Agent B)
13. Авторизованный пользователь может создавать именованные портфели.
14. В портфеле можно моделировать покупку акций: увеличивается позиция, пересчитывается средняя цена, пишется транзакция.
15. Можно моделировать продажу: уменьшение/удаление позиции, запрет продажи больше имеющегося количества.
16. Отображаются себестоимость, рыночная стоимость, P&L (абс. и %).
17. Доступен журнал операций портфеля.

### Дефекты исходника (устранены)
- SECRET_KEY / TOKEN из env
- баг сравнения last_price с None
- кастомный mixin → LoginRequiredMixin
- совместимость с t_tech.invest
